# Office Hours (optional)

> **Optional. 30 minutes after the core.** Nothing here is required. The homework and the next-session preview were handed out in [Module 4](module-4-debrief.md), so you've already got what you need to leave with. Stay if it's useful; drop off if it's not.

This block is unstructured on purpose. It's for the work that doesn't fit in a timed core.

## What it's good for

### Iterate your skill

The core gave you one tight review-and-fix loop. Here you can run several. Bring the skill back, run it against a harder feature, and push on the part that's still weak.

> *"Run this skill against [a messier OpenSpec change]. Where does the output get vague or wrong? Fix the single biggest cause, not all of them."*

### Finish if you didn't

If Module 3 ran out before your skill worked, this is the time. Grab a facilitator. Pairing with someone whose skill is working is usually faster than starting over.

### Go deeper on what people built

Longer show-and-tell than the core allowed. Useful when two rooms built similar skills and want to compare approaches, or when someone's skill did something the rest of the room wants to copy.

### Open Q&A

Anything from the hour that we moved past too fast: context rot in long sessions, when to use a skill vs a CLAUDE.md rule vs just a good prompt, vetting third-party skills, where this is heading in later weeks.

## How to use the time

No agenda. Tell a facilitator what you want: iterate, finish, compare, or ask. We'll cluster people with the same goal.

When you're done, you're done. There's no closing ritual here; the core already had it.
